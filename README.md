# NestGoal

Appli Android pour un couple, qui répond à une seule question : **quand est-ce qu'on achète notre maison ?**

Les données restent sur le téléphone (aucun serveur). Interface web (HTML, CSS, JavaScript sans dépendance)
empaquetée dans une appli Android (WebView), aussi publiée sur GitHub Pages.

## Développement
`python3 -m http.server 8080` puis http://localhost:8080.
